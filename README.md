## Clinical AI Question

Can combining MRI findings (new T2 lesions, gadolinium-enhancing lesions, brain volume loss) with clinical data such as EDSS scores and relapse history help predict disability progression in relapsing MS? A useful model would need independent validation on data from other sites, predictions clinicians can interpret, and patient-level data splits to avoid leakage.
